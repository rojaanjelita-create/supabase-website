Supabase adalah platform backend open source yang membantu pengembang membangun aplikasi. Supabase menyediakan database PostgreSQL, autentikasi pengguna, penyimpanan file, dan API untuk mendukung kebutuhan aplikasi modern.

FITUR // UTAMA

Supabase menyediakan beberapa fitur yang dapat digunakan bersama untuk membangun backend aplikasi.

PostgreSQL adalah sistem database relasional yang digunakan Supabase untuk menyimpan, mengatur, menghubungkan, dan mengambil data aplikasi.

POSTGRESQL SQL DATABASE

Authentication membantu aplikasi menangani pendaftaran akun, login, dan pengelolaan sesi pengguna sesuai metode autentikasi yang dikonfigurasi.

LOGIN DAFTAR SESI USER
